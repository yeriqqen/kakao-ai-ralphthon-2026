3. Simulated call, Confirmed in simulation, Unclear, 가상 환자 정보 표시를 유지합니다.
4. 슬라이드가 5쪽 이하이며 한국어·러시아어 글자가 잘 보이는지 확인합니다.
5. 필요한 마이크 권한과 음성 서비스 처리 안내를 확인합니다. 실제 환자 정보·비밀키·계정 정보·원본 프롬프트·Codex 세션 로그를 첨부하지 않습니다.
