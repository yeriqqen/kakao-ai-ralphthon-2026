# Codex 활용 설명

Codex에 러시아어 문의부터 한국어 마이크 시뮬레이션, 모르는 질문의 왕복 전달, 러시아어 결과와 한국어 가상 시트까지 이어지는 핵심 흐름 구현을 맡겼습니다. 실제 전화 금지, 모르는 개인 정보 추측 금지, 가상 정보 표시라는 조건을 유지했습니다.

공식 제출 안내 확인, 대화 처리 규칙, 브라우저 검증, 발표자료 준비를 병렬로 진행했습니다. 결과가 항상 성공으로 고정되지 않는지 보기 위해 대기 시간을 바꾸고, 답변을 비우고, 불확실하거나 모순된 진술을 입력했습니다. 같은 발화 안의 모순을 발견해 Unclear로 처리하도록 수정했습니다. 로컬 서버 경로 오류도 실제 브라우저 접근 검사로 발견해 수정했습니다.

합성 텍스트와 모의 음성 이벤트를 사용한 자동 검증은 실제 마이크·청취 검증으로 간주하지 않았습니다. 실제 사용자의 가치 검증도 자동 테스트와 구분해 Unverified로 표시했습니다. 원본 프롬프트와 Codex 세션 로그는 제출물에 포함하지 않았습니다.
