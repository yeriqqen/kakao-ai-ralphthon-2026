# YOKOBU — 제출 입력 초안

## 고객과 문제

한국의 외국인 거주자·관광객·농인 및 난청인 중, 지역 서비스에 직접 전화해야만 알 수 있는 정보를 필요로 하는 사용자입니다. 필수적이고 수시로 바뀌는 정보의 마지막 부분이 한국어 전화 뒤에 있어 언어와 청각 접근성 장벽이 생깁니다. 번역 앱, 일반 LLM, 온라인 목록만으로는 실제 통화에서 확인해야 하는 정보를 안정적으로 얻기 어렵습니다.

## 구현한 해결책

YOKOBU는 AI 음성 컨시어지의 로컬 시뮬레이션 데모입니다. 러시아어 문의와 누락된 나이·증상·보험 정보를 받은 뒤 한국어 대화 계획을 보여줍니다. 사용자가 Start simulation을 누르면 한국어 음성을 출력하고, 접수 역할 팀원이 마이크로 답변합니다. 사용자는 텍스트만으로 참여할 수 있습니다.

처음 방문 여부처럼 아직 모르는 질문은 러시아어로 전달하고 사용자 답을 한국어로 돌려줍니다. 이미 수집한 나이는 바로 답합니다. 대화에서 확인한 내용만 러시아어 요약에 포함하고, 미확인·모호한 내용은 Unclear로 남깁니다. 수집한 가상 입력으로 한국어 접수용·진료용 시트를 만듭니다.

## 데모의 사실성과 한계

**실제 전화는 걸지 않습니다. 실제 병원 정보나 환자 정보가 아닙니다.** 모든 화면과 결과는 Simulated call / Confirmed in simulation / 데모용 가상 정보 표시를 유지합니다. 한국어/러시아어 의미 처리는 정해진 표현에 대한 로컬 규칙이며 범용 LLM 또는 실시간 통번역 API는 연결하지 않았습니다. 브라우저 음성 인식과 음성 합성을 사용하며 권한과 서비스 가용성에 영향을 받습니다.

핵심 텍스트 흐름, 예상 대비 실제 결과, 빈 입력·미응답·모호함·모순·변경된 대기 시간 처리를 자동 검증했습니다. 자동 음성 이벤트는 실제 마이크 검증과 구분합니다. 최신 실제 기기 상태는 함께 제공하는 검증 요약을 확인해야 합니다. 실제 사용자 피드백이 없어 사용자 가치 가설은 **Unverified**입니다.

검색, 프로필 저장, 여러 장소 추천, 다른 서비스 유형, 녹음, 후속 서비스는 오늘 범위에 없습니다. 두 스마트폰 동기화는 구현하지 않았습니다.
