# How we used Codex

The team defined the users, language choices and simulated-call acceptance requirements. Codex built the customer chat, generated call plans, a Korean Realtime business screen and shared call state while preserving v1. Earlier work split across interface, conversation, audio and submission tasks. The polished UI was later integrated through PR #1, with newer local work preserved before switching branches.

Codex tested the boundaries between the UI, server and model. The current checkpoint has 67 unit tests, 30 actual localhost HTTP checks with mocked AI, 20 mocked customer UI checks, 19 mocked business UI checks, and 32 design checks. The build and eight extracted-package checks also pass. These checks do not establish a working live conversation or user value.

Actual microphone rehearsals exposed failures that these tests initially missed. The voice assistant skipped a business question about another color and repeated questions after claiming it understood the answers. Codex added server detection of explicit customer questions and tested the recorded question through real OpenAI requests. A separate review found that the HTTP route discarded the saved transcript's call identity before confirmation validation. Passing the saved record fixed that integration defect, and a new HTTP regression exercises relay, required answers, readback, confirmed completion and final summary. The fourth microphone run then demonstrated the live relay and Korean return, but revealed another defect: the plan did not adapt to the accepted alternative and inferred pickup impossibility from stock. The current repair updates the affected targets, retains applicable recorded answers, and proactively asks about offered alternatives. Six checks on a three-request real API replay pass; the fifth microphone run then completed normally, including proactive clarification of an offered black alternative, accepted-choice adaptation, supported answers, readback, summary and shutdown. The user confirmed the audio and stopped microphone. Later teammate UI/shutdown changes passed separate regressions.

Other observed failures included social greetings treated as stock answers, overlapping replies that left the microphone paused, transcription repeating its own prompt, and recommendations strengthening an uncertain price. Repairs introduced speech-intent guards, playback sequencing, removal of the transcription prompt, and constrained recommendation choices that reuse the recorded facts. The original failures remain in the evidence. A replay or test passing does not erase the original failure or prove the live path.

Real Russian and Chinese checks also revealed meaning-preservation problems. The team distinguishes tested interface localization from model fidelity. No actual target-user feedback has validated the product hypothesis, so user value remains Unverified. This explanation contains no raw Codex prompts or session logs.
