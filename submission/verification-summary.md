# YOKOBU 검증 요약

모든 병원 사실과 환자 상세 정보는 **가상 시뮬레이션**입니다. 실제 병원에 전화하지 않았습니다.

| 검증 대상 | 기대 결과 | 실제 결과 |
| --- | --- | --- |
| 핵심 로직 | 대화에서 받은 사실만 반영 | Node 테스트 **15/15 통과** |
| 지정 가상 예시 | 6가지 사실, 정확한 러시아어 요약, 2개 한국어 시트 | 합성 텍스트 비교 **14/14 통과** |
| 화면 흐름 | 요청 → 필수 정보 → 계획 → 명시적 시작 → 질문 전달 → 결과 | Chrome 자동 확인 **11/11 통과** |
| 예상 밖 질문 | 처음 방문 여부를 추측하지 않고 러시아어로 질문 | “Вы впервые в этой клинике?” → “Да” → “네, 처음 방문입니다.” 확인 |
| 실패 경로 | 빈 요청, 미응답, 모호함, 모순에서 허위 성공 방지 | 안내·대기·Unclear 표시 확인 |
| 변경된 응답 | 대기 시간이 바뀌면 실제 입력값 반영 | 45분 입력 시 45분 요약 확인; 15분 기본값 출력하지 않음 |
| 마이크 거부 | 답변을 만들지 않고 권한 안내 | **합성 권한 거부 이벤트**로 동작 확인; 실제 OS 거부 검증은 아님 |
| 실제 마이크 대화 | 팀원 목소리 인식 후 결과 반영 | **Unverified** — 실제 기기 실행 근거 대기 |
| 실제 한국어 청취 | 팀원이 AI 음성을 들음 | **Unverified** — 브라우저 재생 완료 이벤트만 관찰, 사람의 청취 확인 대기 |
| 사용자 가치 | 실제 대상 사용자에게 도움이 되는지 | **Unverified** — 사용자 피드백 없음 |

합성 예시의 기대/실제 러시아어 요약은 일치했습니다:

> Клиника открыта. Женщина-врач сегодня не принимает, но доступен другой врач. Принимают без корейской государственной медицинской страховки. Консультация — примерно 20 000 вон. Сейчас ожидание — 15 минут.

한국어 시트:

- 접수용: 나이: 7세 / 건강보험: 국민건강보험 없음.
- 진료용: 증상: 기침 / 증상 기간: 2일.
- 두 시트 모두: **데모용 가상 정보 — 실제 환자 정보 아님.**

언어 해석과 대화는 제한된 로컬 규칙으로 구현했습니다. 범용 LLM·번역 API·실제 전화는 연결하지 않았습니다. 음성 인식과 합성은 브라우저 API이며 인터넷·권한·기기 환경에 따라 달라집니다. 두 스마트폰 동기화는 구현하지 않았습니다. 검색, 지속 프로필, 여러 장소 추천, 다른 서비스, 녹음, 후속 서비스는 범위 밖입니다.

로컬 상세 근거: `docs/verification.md`, `artifacts/expected-vs-actual.json`, `artifacts/browser-results.json`. 이 제출 요약에는 원본 프롬프트나 Codex 세션 로그를 포함하지 않았습니다.
